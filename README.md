# BladeLab

手机优先的单局 3D 锻造。每批三块原石，可比较真实 3D 缩略图并拖动检视。免费打灯和敲石帮助观察透光、亮点和密实度；擦窗每块花费 3 CR，只展示局部矿相，不保证品质。切开后查看纯净度、稳定性，并可切换同源钢纹预览。按住鼓风、松手散热，让原石经过熔炼球再浇注成坯。

直接点刀身落锤，键盘可以用空格敲击刀腹。刀腹偏纹，刃侧偏膜，刀尖偏特效。第 30 锤断率为 50%，第 45 锤起为 90%。看到值得留下的纹样后可以收锤。装配三选一时仅覆盖柄区。选料、装配和鉴定时可拖动模型。

## 02 精炼

熔化后有 12 秒排渣时间，绿区从原来的 13° 收窄到 7°，随炉况缓慢移动。鼓风有余热惯性，松手后温度仍会短暂上升。在绿区中央排渣更快，离开绿区会损失少量质量。熔炼满 3 秒且质量达到 22 后可以主动浇注，也可继续控温争取更好结果。

| 成坯结果 | 质量 | 纯净度变化 | 稳定性变化 | 成刀基础属性变化 |
| --- | --- | --- | --- | --- |
| 精炼极佳 | 86–100 | +20 | +18 | +8 |
| 精炼良好 | 65–85 | +10 | +8 | +3 |
| 普通成坯 | 40–64 | +2 | −4 | −1 |
| 勉强成坯 | 22–39 | −12 | −18 | −7 |

变化受属性上下限约束，纯净度和稳定性继续影响成刀属性与锻打断率；精炼质量同时改变刀面的杂质和粗糙度，保留原矿底色与纹理身份。

8 秒内未熔化、排渣结束时质量不足 22，或过热 / 凝固造成损伤达到 100%，都会真正报废本炉。86° 以上烧损、55° 以下凝固，损伤会累积，先有温度提示与损伤条预警；及时补救仍可成坯。失败消耗已付原料，不重复扣款、不生成藏刀；再开一炉仍保证能购买最低价原石。旧版未结束的精炼重新从本阶段开始，已买矿石、余额和藏刀保留。

`node scripts/qa-refining.mjs` 使用手机页面的实际鼓风与浇注按钮，检查四档成坯、四种废炉原因、刷新续炼、失败复位与同矿刀胚画面差异。

## 本地运行

需要 Node.js 22+。静态网页可直接部署，无需下载依赖。

```sh
npm start
npm test
```

打开 http://127.0.0.1:8217/。原型使用独立的浏览器本地记录，旧项目的藏刀和信用点数据无需迁移。

## 选料 V5

- 5 类基础矿形，每类原型 + 3 个轻变体；每款 642 顶点 / 1,280 三角面 / 约 24 KB。`node scripts/build-ore-models.mjs` 可重建全部 20 款。
- 12 种材质拥有独立石皮、矿芯和钢色。露脉、裂隙、亮点、密实度和石皮厚薄以实际表面、光照、回音和擦窗表现。
- 切面取真实网格交线，双面共用矿相坐标与种子；刀胚和成刀沿用同一矿料身份，锤击继续叠加工艺。预览只展示底层钢纹，不保证最终锤击结果。
- 擦窗花费与开料分开，重复擦窗不扣费；余额不足以同时擦窗和买下当前矿石时禁用。旧存档兼容。
- `ore-catalog.html` 为美术检视工具，可查看全部矿形、切面和对应刀身。

### 矿芯底色与透澈变化

新原矿在 5 类矿形、12 种石皮之外，独立生成 16 种矿芯底色、藏矿 / 隐露 / 外露状态和连续的透澈程度。同一矿种可藏不同颜色，清澈程度不代表品质。藏矿在自然光下不泄露矿芯底色，隐露随观察角度改变，外露可直接看见局部颜色；擦窗与切面揭晓真实内芯。浑浊矿芯有乳雾夹杂，清透矿芯呈现内层色泽、较低粗糙度与镜面反射。底色和矿料组织传递到刀胚与刀身，透澈差异转为金属底面的雾感与抛光差异，装配仍只覆盖柄区。此前已购买的原矿保留原有材质色系。

### 检视灯光

选料检视灯只保留打灯：有明确的白色光斑与矿芯色晕，回应由石皮厚度、通透程度和擦窗状态决定。未透光时保留表皮光斑并给出简短观察结果。再次点击关闭，切换矿石后回到自然光。敲石和付费擦窗继续可用。`scripts/qa-ore-inspection.mjs` 检查五类矿石的实际 WebGL 画面差异、局部亮度、浑浊 / 清透响应，以及关闭后的恢复与免费检视。
